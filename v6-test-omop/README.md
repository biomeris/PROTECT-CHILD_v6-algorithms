
# v6-test-omop

Test algorithm for validating connectivity and data extraction from an OMOP Common Data Model (CDM) database through the Vantage6 infrastructure.

This repository is intended exclusively for development, integration, and troubleshooting purposes. It is used to verify the correct configuration of database connections, authentication parameters, and data access mechanisms within a Vantage6 node.

The algorithm is **not part of the final catalogue of study algorithms** and is **not intended for operational use in federated analyses**. Instead, it serves as:

- A reference implementation for configuring OMOP database connections in Vantage6.
- A testing utility for validating node and database integration.
- An example for developers who need to build new OMOP-based algorithms.
- A troubleshooting tool for diagnosing connectivity and data access issues.

The repository may contain simple demonstration queries whose sole purpose is to confirm that the infrastructure is correctly configured and able to access the target OMOP database.
